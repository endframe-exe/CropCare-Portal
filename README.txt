CropCare — Crop Disease Information & Prevention Portal (Report 2 Website Package)
Course: Web Designing (DCSE0152) — Module 1, Module 2, Module 3 (CSS), and Module 4 (JavaScript)
Team: B.Tech CSE (Data Science — DS-A), Group 11, NIET Greater Noida

FILES INCLUDED IN THIS ZIP:
1. index.html                -> Main HTML5 webpage (links style.css and script.js)
2. style.css                 -> External CSS stylesheet (Module 3: Responsive Design using CSS)
3. script.js                 -> External JavaScript file (Module 4: Interactive Website using JS)
4. cropcare_standalone.html  -> All-in-one single HTML file (CSS & JS combined inside one file)
5. images/                   -> Local backup images (hero_farmland.jpg, tomato_early_blight.jpg, rice_blast.jpg, wheat_rust.jpg)

HOW TO RUN IN VS CODE:
1. Extract (Unzip) this folder on your computer.
2. Open Visual Studio Code and click File -> Open Folder to open the unzipped folder.
3. Right-click on index.html and select "Open with Live Server" (or double-click index.html to open it in Chrome/Edge).
